# Tafara Mawere — Portfolio (Legacy)

An earlier static portfolio and CV presentation site built with HTML and CSS, with local image assets and project highlights.

## Contents

- Personal introduction and skills overview
- Portfolio project cards
- CV-style education and experience content
- Static image assets and front-end styling

## Technology

- HTML5
- CSS3
- JavaScript and browser/CDN assets used by the page

## Run locally

Clone the repository and open `index.html` in a browser, or serve the folder with a static web server.

```bash
git clone https://github.com/Benefits2PointOh/tafara-mawere-portfolio.git
cd tafara-mawere-portfolio
```

## Status

Legacy portfolio version retained for reference. The newer CV-download portfolio is maintained separately.

## Note

Some asset paths and project links reflect the original hosting layout and may require adjustment when deployed under a different base URL.
